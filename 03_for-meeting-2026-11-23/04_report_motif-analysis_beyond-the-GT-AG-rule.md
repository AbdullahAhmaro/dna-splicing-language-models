**How to read this.** The motif rule (04) calls a window a donor if it has GT at offset 301 (or AC at 298, the same motif on the other strand), and an acceptor if it has AG at 298 (or CT at 301). Otherwise it says *none*. Each model column is the frozen language model with the MLP head and the pooling variant chosen on a validation split (07), never on test. Cells give the fraction correct, (correct / total), and a 95% interval for groups under 100. For splice sites, correct means the right site type (recall). For non-sites, it means calling them *none*.

GC-AG introns (a GC donor instead of GT) are the known minor class of human introns, about 1% of them. GC reads as GC on both strands (it is its own reverse complement), so a − strand GC donor shows GC at offset 298.

## 3. Is the motif inside the centre token?

The centre token is the token covering base 300. NT-v2 always cuts the window into 6-mers from base 0, so its centre token is always bases 300–305. It contains GT@301 (+ strand donors) and CT@301 (− strand acceptors), but AG@298 and AC@298 sit in the previous token. DNABERT-2's tokens vary in length, so its centre token varies per window. ## 4. Control: is it just base composition?

Negative windows in this dataset are more AT-rich than splice-site windows (see `dataset_format.md`), so a model could reject decoys from overall composition rather than splice signals. This control gives the motif rule a gate that only sees composition: mono- and dinucleotide frequencies of the whole window, logistic regression trained on the motif-bearing training windows. Its threshold is set to keep the same share of canonical sites as each model. That threshold is set on the test sites themselves, which favours the control. Composition alone separates decoys from real sites with AUC 0.66.

| model | model keeps (canonical sites right) | model rejects decoys | composition gate rejects decoys, at the same share of sites kept |
|---|---:|---:|---:|
| NT-v2-50M (`center_plus_prev_concat`) | 0.965 | **0.712** | 0.043 |
| DNABERT-2 (`center_plus_prev_concat`) | 0.835 | **0.815** | 0.321 |

If composition explained the models' advantage, the last two columns would be close. A large gap means the models use sequence information beyond overall base composition.
