# Phase 1 summary: splice-site classification with frozen DNA language models

_Generated by `scripts/06_summary.py` on 2026-11-22 16:44 UTC from `results/phase1_results.json` and `results/embed_stats.json`._

## The dataset

`InstaDeepAI/nucleotide_transformer_downstream_tasks_revised`, task `splice_sites_all`: human splice sites from GENCODE V44 (the Nucleotide Transformer revised downstream benchmark). Every row is a 600-nt DNA window with one label for the whole window: is the centre of the window a **donor** site (exon→intron), an **acceptor** site (intron→exon), or **neither**. 30,000 train and 3,000 test windows, roughly balanced, with the test set on held-out chromosomes. It is window classification. It is not locating a cut point inside a long sequence. Details: `results/dataset_format.md`.

- Label values: `0` = none, `1` = acceptor, `2` = donor. **Inferred** from motif enrichment, because the dataset card does not document them.
- Windows are on the genome + strand. About half the sites appear reverse-complemented: donors show GT at offset 301 in 51% of rows and AC at offset 298 in 51%. Acceptors show the same split with AG and CT.

## How many sequences were used

| method | train rows | test rows |
|---|---:|---:|
| NT-v2-50M embeddings + heads | 8,000 of 30,000 (class-stratified, seed 42) | 2,000 of 3,000 |
| DNABERT-2 embeddings + heads | 8,000 of 30,000 (class-stratified, seed 42) | 2,000 of 3,000 |
| GT/AG baselines | none (the strand-aware offsets are picked on all 30,000 train rows) | 2,000 (same rows as the models); 3,000 full test in the JSON |

The MLP head is fit on 90% of its train rows. The other 10% is its early-stopping validation split. Logistic regression is fit on all train rows.

## Which model won

**DNABERT-2 + MLP head** beat NT-v2-50M + MLP head by **1.4 percentage points of accuracy** (0.549 vs 0.535) and 0.6 points of macro-F1 (0.524 vs 0.518). The accuracy gap is within the ~±3.1 pp sampling noise of the difference, so this is not a clear win.

**With position-aware pooling the answer changes.** With each model's pooling variant chosen on a validation split (never on test; see *Choosing the pooling variant without the test set*), **NT-v2-50M `center_plus_prev_concat`** (0.941 accuracy, 0.940 macro-F1) beats DNABERT-2 `center_plus_prev_concat` (0.827, 0.826) by **11.4 points**. That gap is larger than the ~±2.0 pp sampling noise. The full-window comparison above mostly measured how much each model's average washes out the centre.

## The no-ML baseline

- **As specified** (one offset, GT→donor, AG→acceptor, best offset 301 chosen on test): accuracy **0.497**, macro-F1 0.429 on the model test rows (0.496 / 0.428 on all 3,000). Picking the offset on train instead gives offset 298 and 0.485. This rule is capped near 0.5: one offset sees only the + strand motif of one site type, because donor GT and acceptor AG sit at different offsets and half the windows are reverse-complemented.
- **Strand-aware** (same motifs, reverse complements included, offsets picked on train only): accuracy **0.888**, macro-F1 0.886 (0.896 / 0.894 on all 3,000). This is the fair no-learning reference point.
- Best frozen model with full-window mean pooling vs the strand-aware rule: DNABERT-2 + MLP is **33.9 points below** it.

## Choosing the pooling variant without the test set

Protocol: a selection split of 800 training rows (10%, class-stratified, seed 42) is held out. For each variant, the same MLP recipe is trained on the other 7,200 rows. It carves its own early-stopping split from those, so it does not reuse 03's early-stopping split (the two overlap by 91 rows, about the 80 expected by chance). The variant with the best selection-split accuracy is chosen. Its final number is the test score of the 03 head refit on all training rows. The test set plays no part in the choice.

### 4. Control: is it just base composition?

Negative windows in this dataset are more AT-rich than splice-site windows (see `dataset_format.md`), so a model could reject decoys from overall composition rather than splice signals. This control gives the motif rule a gate that only sees composition: mono- and dinucleotide frequencies of the whole window, logistic regression trained on the motif-bearing training windows. Its threshold is set to keep the same share of canonical sites as each model. That threshold is set on the test sites themselves, which favours the control. Composition alone separates decoys from real sites with AUC 0.66.

| model | model keeps (canonical sites right) | model rejects decoys | composition gate rejects decoys, at the same share of sites kept |
|---|---:|---:|---:|
| NT-v2-50M (`center_plus_prev_concat`) | 0.965 | **0.712** | 0.043 |
| DNABERT-2 (`center_plus_prev_concat`) | 0.835 | **0.815** | 0.321 |

If composition explained the models' advantage, the last two columns would be close. A large gap means the models use sequence information beyond overall base composition.

## Limitations

- **The backbone is frozen, not fine-tuned.** Only a small head on top of a fixed vector is trained. The headline published results for these models on this benchmark come from fine-tuning (all weights, or parameter-efficient adapters), so these numbers should sit **below** published fine-tuned results. They are a lower bound on what these models can do, not a measure of it.
- **Pooling choice.** The reported variant is chosen on a validation split carved from train, not on test. The full variant table is shown on test for description only.
- **Small non-canonical group.** Only a handful of true splice sites lack the canonical motif (see the motif analysis), so recall on them has a wide interval. The decoy rows and the composition control carry most of the evidence that the models use more than the motif.
- **Subsampled data.** Each model saw a class-stratified subset of the 30,000 training windows (see the sequence counts above) to keep a CPU run under an hour. `--max-train -1 --max-test -1` uses everything.
- **One seed, untuned heads.** One train/validation split and default hyperparameters, with no repeated runs. The ±95% intervals cover test-set sampling only, not training variance.
- **Label names are inferred**, not documented. The motif evidence is overwhelming (see `dataset_format.md`) but it is still an inference.
- **Baseline selection.** The as-specified rule's offset was picked on the test set, as requested, which flatters it slightly. The strand-aware rule's offsets were picked on train only.
- **The task differs from the advisor's framing.** This benchmark classifies a pre-centred window. Finding *where* to cut inside a long sequence is a different, harder task. It is closer to sliding this classifier along the sequence or to per-token prediction (SpliceAI-style).
